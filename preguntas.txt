¿Qué ocurre si cambias el valor de la variable desde la consola? ¿Se puede?
- La variable pasará a tener el valor dado. Sí se puede.

¿Para qué sirve la consola del navegador en este contexto?
- Para testear y depurar el código, así como hacer pruebas. 

Para qué sirve el archivo HTML en este contexto?
- Para determinar los elementos y su estructura de la página web.

¿Por qué es una buena práctica separar el código JavaScript del HTML?
- Porque de esta manera el código Javascript es reutilizable, además de por organización y limpieza.
 
Por qué se llama Vanilla JavaScript?
- Porque es Javascript sin librerías ni frameworks.

Cuándo se usa JavaScript puro y cuándo se usan frameworks o librerías como REACT?
- Vanilla Javascript se usa para aprendizaje o proyectos pequeños, los frameworks y librerías se usan en proyectos grandes.
